# TaskFlow

TaskFlow is a planned web-based project and task management system with AI assistance. It is intended to help teams organize projects, assign and track tasks, and plan work collaboratively.

## Planned features

- Project and team management
- Task assignment, prioritization, deadlines, and progress tracking
- Task comments and activity history
- AI Task Suggestions
- AI Task Breakdown

## Planned technology

HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, JWT authentication, and Git/GitHub.

See [docs/PHASE_1.md](docs/PHASE_1.md) for the project definition, initial planning, and development phases. This repository currently contains Phase 1 planning and setup only; the application features are not yet implemented.
